# kr1-html-css-shop — ShopProject

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».
Дисциплина: «Фронтенд и бэкенд разработка».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина без CSS-фреймворков.

## Ссылка на опубликованный проект

GitHub Pages: https://uksovilya.github.io/kr1-html-css-shop/

## Структура проекта

```
kr1-html-css-shop/
├── index.html      — главная: hero, преимущества, популярные товары, модальное окно
├── catalog.html    — каталог: сетка карточек, категории, sticky-блок фильтров
├── product.html    — карточка товара, таблица характеристик
├── order.html      — страница оформления заявки
├── contacts.html   — контактная информация
├── css/style.css   — единый файл стилей
├── js/main.js      — открытие/закрытие модального окна, валидация формы
├── images/         — изображения
├── README.md
└── .gitignore
```

## Используемые технологии

HTML5, CSS3 (переменные, Flexbox, Grid), минимальный JavaScript, Git, GitHub Pages.

## Как посмотреть проект

1. Открыть ссылку GitHub Pages, **или**
2. Клонировать репозиторий и открыть `index.html` в браузере (сервер не нужен).

## Что реализовано по требованиям

- 5 страниц, у каждой уникальные `title` и `meta description`, один `main`, единая навигация;
- семантика: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- якорные ссылки (`index.html#advantages`, `index.html#popular`, `#contacts`);
- карточки товаров, таблица (`caption`, `thead`, `tbody`, `th`, `td`), форма заявки, модальное окно на `<dialog>`;
- CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox (шапка, меню, кнопки) и Grid (каталог, карточки, страница товара, контакты);
- БЭМ-именование (`product-card__title`, `product-card--discount`, `site-nav__link--active` и т. д.);
- позиционирование: `sticky` (шапка, фильтры), `absolute` (бейджи в карточках), `relative` (карточка), `fixed` (кнопка «Наверх»), `z-index`.

## Самостоятельные доработки

- бейджи «Хит», «Новинка», «Скидка» и БЭМ-модификаторы карточек;
- категории товаров и хлебные крошки;
- кнопка «Наверх», подсветка активного пункта меню (`aria-current`);
- доступность: подписи полей, `aria-invalid`, `aria-describedby`, видимый фокус, `role="status"` у сообщения;
- закрытие модального окна кликом по фону, сброс ошибок при вводе;
- плавная прокрутка, адаптивная перестройка сеток (`@media`).
